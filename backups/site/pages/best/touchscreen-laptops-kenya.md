## How we ranked them

Each laptop gets a spec score out of 42, read from its listing: processor class ×3 (Celeron 1, Core i3 2, Core i5 3, Core i7 / Core Ultra 5 4, Core i9 / Core Ultra 7 / Apple M 5), processor age ×2 (Intel 7th gen and older 0–1, 8th–9th gen 3, 10th 4, 11th 5, 12th 6, 13th gen, Core Ultra and Apple M 7), memory (8 GB 3, 16 GB 6, 24 GB+ 8) and storage (256 GB 2, 512 GB 4, 1 TB+ 5). Ties go to the lower price. Nobody paid for a place, and no laptop is ranked by hand. Specs are read from each product's listing as the shop typed it; where a listing does not state the memory or storage, the laptop scores 1 point for it and the con says so, so check the product page or ask us.
