- **Tight budget:** Core i7. Its median is KSh 52,000 and the cheapest is KSh 22,000.

## Verdict

Core i7 costs less at the median (KSh 52,000 against KSh 145,500). Core Ultra leads on multitasking and heavy apps; Core Ultra leads on the longest software support. Either way, compare the exact model: the spread inside each group is wider than the gap between them.

## How we compared them

Every Core Ultra and Core i7 laptop in stock is counted, not a sample. Shares are of each side's own total. The best picks use the same spec score as our lists: processor class ×3 (Celeron 1, Core i3 2, Core i5 3, Core i7 / Core Ultra 5 4, Core i9 / Core Ultra 7 / Apple M 5), processor age ×2 (Intel 7th gen and older 0–1, 8th–9th gen 3, 10th 4, 11th 5, 12th 6, 13th gen, Core Ultra and Apple M 7), memory (8 GB 3, 16 GB 6, 24 GB+ 8) and storage (256 GB 2, 512 GB 4, 1 TB+ 5).
