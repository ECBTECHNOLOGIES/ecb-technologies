## Which should you buy?

- **Tight budget:** Core i5. Its median is KSh 31,000 and the cheapest is KSh 21,000.
- **For multitasking and heavy apps:** Core i7 (more of its models have 16 GB RAM or more).
- **For the longest software support:** Core i7 (more of its models have a 10th-gen or newer processor).
- **Highest spec available:** Core i7, up to KSh 170,500.

## Verdict

Core i5 costs less at the median (KSh 31,000 against KSh 52,000). Core i7 leads on multitasking and heavy apps; Core i7 leads on the longest software support. Either way, compare the exact model: the spread inside each group is wider than the gap between them.

## How we compared them

Every Core i5 and Core i7 laptop in stock is counted, not a sample. Shares are of each side's own total. The best picks use the same spec score as our lists: processor class ×3 (Celeron 1, Core i3 2, Core i5 3, Core i7 / Core Ultra 5 4, Core i9 / Core Ultra 7 / Apple M 5), processor age ×2 (Intel 7th gen and older 0–1, 8th–9th gen 3, 10th 4, 11th 5, 12th 6, 13th gen, Core Ultra and Apple M 7), memory (8 GB 3, 16 GB 6, 24 GB+ 8) and storage (256 GB 2, 512 GB 4, 1 TB+ 5). Ties go to the lower price. Nobody paid for a place, and no laptop is ranked by hand.
